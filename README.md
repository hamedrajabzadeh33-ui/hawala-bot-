# ربات تلگرام صدور خودکار عکس حواله صرافی 🏛️

این ربات پیام متنی حواله را از تلگرام دریافت کرده و دقیقاً مطابق قالب رسمی سند صرافی، یک عکس باکیفیت و خوانا با فونت رسمی و طلایی تولید و ارسال می‌کند.

---

## 🚀 ویژگی‌های کلیدی
- **طراحی سند دقیق و شکیل:** دارای کادر دوبل سرمه‌ای-طلایی، فونت استعداد، پس‌زمینه کاغذی و هدر شکیل.
- **قانون خط چهارم:** اگر خط چهارم خالی باشد، به صورت خودکار آدرس پیش‌فرض (کابل) درج می‌شود؛ در صورت درج نام ولایت دیگر (مثل کندهار یا هرات)، آدرس همان شهر در فوتر ثبت می‌گردد.
- **مدیریت آدرس‌ها در تلگرام:** دارای منوهای دکمه‌ای برای افزودن آدرس جدید، حذف آدرس‌ها و تعیین آدرس پیش‌فرض.
- **آماده برای Render.com:** دارای Dockerfile اختصاصی همراه با کرومیوم و پکیج فونت‌های فارسی که حروف هرگز جداجدا یا مربعی نمی‌شوند.

---

## 📋 مراحل راه‌اندازی سریع در ۲ دقیقه

### گام ۱: ساخت ربات در تلگرام
1. در تلگرام وارد ربات [BotFather@](https://t.me/BotFather) شوید.
2. دستور `/newbot` را بفرستید.
3. یک نام نمایشی و یک نام کاربری (که به `bot` ختم شود) وارد کنید.
4. توکن API را کپی کنید (چیزی شبیه: `7123456789:AAFxxx...`).

### گام ۲: آپلود در GitHub
1. وارد حساب کاربری خود در [GitHub](https://github.com) شوید.
2. یک مخزن جدید (New Repository) ایجاد کنید (مثلاً با نام `telegram-voucher-bot`).
3. تمام فایل‌های این پروژه را در مخزن خود آپلود یا Push کنید.

### گام ۳: راه‌اندازی رایگان در Render.com
1. در [Render.com](https://render.com) ثبت نام کرده یا وارد شوید.
2. روی دکمه **New +** کلیک کرده و گزینه **Web Service** را انتخاب کنید.
3. مخزن گیت‌هاب خود را متصل کنید.
4. در بخش **Runtime**، گزینه **Docker** را انتخاب نمایید (داکرفایل تمام نیازمندی‌های تصویری را خودکار کانفیگ می‌کند).
5. به بخش **Environment Variables** بروید و متغیر زیر را اضافه کنید:
   - **Key:** `BOT_TOKEN`
   - **Value:** [توکن کپی شده از BotFather]
6. روی **Deploy Web Service** کلیک کنید! پس از ۱ الی ۲ دقیقه ربات شما به صورت ۲۴ ساعته آنلاین خواهد بود.

هدایت الله برای عبدالرحیم

- خط ۲: مبلغ
- خط ۳: فرستنده برای گیرنده
- خط ۴: نام ولایت (اختیاری)
